The app's base button (Sora 700, 12px radius, 1.5px border); use for every in-app action.
```jsx
<Button variant="primary">Start game</Button>
<Button variant="fire">Fire now</Button>
<Button variant="link">Clear</Button>
```
- primary takes the companion colour (--pal); disabled = opacity .45. Focus ring is 3px gold.
